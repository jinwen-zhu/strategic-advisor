# Strategic Advisor Skill

把 AI 从"执行者"切换成"战略参谋"的技能包。

在动手之前，它要求 AI 先用选择题问清你的真实目标、可用资源和约束条件，把零散线索梳理成结构，确认之后才执行。

## 它解决什么问题

| 默认模式 | 装上这个 skill 之后 |
| --- | --- |
| 你提一句，AI 立刻开干 | AI 先判断这件事该怎么定义，再问你 2-3 个关键问题 |
| 做完发现方向错了，返工 | 方向在动手前就被校准 |
| AI 替你思考 | AI 帮你思考，决定权仍在你手上 |
| 问题越问越多，没完没了 | 只在答案会改变行动时才问，你随时可以喊停 |

## 安装

技能包的结构就是一个 `SKILL.md`，安装 = 把整个目录放进对应工具的 skills 目录。

**Trae（全局）**

```bash
git clone https://github.com/jinwen-zhu/strategic-advisor.git ~/.trae-cn/skills/strategic-advisor
```

**其他支持 SKILL.md 约定的 AI 工具**

把仓库目录整体复制到该工具的 skills 目录下，确保最终路径形如 `.../skills/strategic-advisor/SKILL.md`。

**只想在单个项目里用**

放到项目根目录下该工具约定的 skills 目录即可，不污染全局配置。

安装后重启会话，让它重新加载技能列表。

## 怎么用

不需要记命令，正常说话就行。以下说法会自动触发：

- "帮我做一个……"
- "我想学……"
- "这两个方案该怎么选……"
- "先别动手，先问我"

也可以显式点名：`用 strategic-advisor 的方式帮我理一下这件事`。

## 它长什么样

**你**：我想学 GitHub。

**普通 AI**：先注册账号，然后 `git init`、`git add`、`git commit`……（一段教程）

**这个 skill**：

> 对零基础的人来说，"学 GitHub"混着三件不同的事：版本管理、代码托管、协作文化。三者的路径差别很大，先摸清你的情况。
>
> 1. 你学它最主要是为了解决什么问题？
>    1) 管好自己的代码　2) 使用别人的开源项目　3) 团队协作　4) 作品展示与上线
> 2. 你的代码基础到哪一步？
>    1) 完全零基础　2) 写过代码但没用过命令行　3) 会用命令行但没用过 Git
> 3. 你能稳定访问 github.com 吗？
>    1) 能　2) 时好时坏　3) 打不开

然后它会把答案收敛成「目标 / 资源 / 约束 / 成功判据 / 风险」五栏，请你确认，再给方案。

## 想改它

直接编辑 `SKILL.md`，最常改的三处：

- **提问形式**：默认选择题；想要开放式追问，改「提问（选择题）」一节
- **追问上限**：默认不设轮数，改「边界」一节
- **启用范围**：觉得它对小事太啰嗦，把「何时不启用」的阈值调低
